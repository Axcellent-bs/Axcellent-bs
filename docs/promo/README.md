# AXcellent 홍보 웹페이지 (초안)

AXcellent 홍보 브로셔(PDF) 내용을 한 페이지로 옮긴 정적 웹페이지다. 사내 AXcellent 화면(`frontend/`)과는 따로 두고, 외부에 보여 줄 소개용으로만 쓴다.
상태: **초안, 공개 전.** 공개 위치(호스팅)와 연락 수단이 정해지지 않았고 `noindex`라 검색에 나오지 않는다. 작성: 배병환, 2026-11-18.

## 폴더
| 파일 | 하는 일 |
| --- | --- |
| `content.mjs` | **모든 문구·숫자·링크가 여기 한 곳에 있다.** 고칠 때는 이 파일만 고친다 |
| `build.mjs` | `content.mjs`를 읽어 `index.html`을 만든다 (외부 패키지 없음) |
| `index.html` | 만들어진 결과. 직접 고치지 않는다 |
| `style.css`, `app.js` | 모양과 아주 작은 동작(메뉴, 스크롤 나타나기). JS를 꺼도 읽힌다 |
| `assets/` | 사진·화면 캡처·로고. 시연 영상·화면은 `assets/demo/`에 넣는다 |
| `INTAKE.md` | 준하 님께 받을 자료와 넣는 곳 |

## 보는 법·고치는 법
```bash
cd docs/promo
node build.mjs      # content.mjs → index.html
```
만들어진 `index.html`을 브라우저로 열면 된다(서버 없이 열린다). 글꼴(Pretendard)만 인터넷에서 받는다.

## 지금 일부러 비워 둔 것 (비어 있으면 그 버튼·칸은 화면에 안 나온다)
- `links.brochureUrl` — 브로셔 PDF 받기. PDF 검수가 끝나고 공개하기로 정한 뒤에 채운다
- `links.contactUrl`·`links.contactNote` — 상담 연락 수단(Instagram DM, 이메일 등)이 정해지면 채운다
- `story.media` — 시연 영상·화면. 준하 님 자료가 오면 채운다(`INTAKE.md`)
- `site.noindex` — 공개하기로 정하면 `false`로 바꾼다

## 브로셔 PDF와 다른 점 (확인 필요)

| 4 | "서버도 데이터도 회사 것입니다" 설치 문구(13쪽) | PDF 그대로 | 재헌·태윤 |

| 6 | 14쪽 누비투어 "연결 준비 중" | PDF 그대로 | 예진 |

## 숫자와 출처 (준하 님 확정 필요)
36초(감지부터 기록까지), 17건(AI끼리 주고받은 요청), 실패 주문 7건, 영향 고객 6명, 피해 249,000원, 보상 12,000원. 모두 **시연 환경(가상 데이터)**이며, 출처는 "시연 이슈 기록(시스템이 자동으로 잰 시각)"이다. 어느 시연 이슈 번호인지 정해지면 `story.statsSource`에 적는다. 같은 숫자는 브로셔·인스타 게시물·이 페이지가 모두 같아야 한다(합의 문서는 63초를 36초로 고칠 것).
