# 준하 님 자료 받는 자리

준하 님이 만드는 자료를 홍보 웹페이지에 넣는 방법이다. **파일을 `assets/demo/`에 넣고 → `content.mjs`의 해당 칸을 채우고 → `node build.mjs`** 순서다. 받는 쪽(병환)이 반영한다.

## 받을 자료와 넣는 곳

| 자료 | 형식·한도 | 파일 위치 | `content.mjs` 칸 |
| --- | --- | --- | --- |
| 결제 장애 시연 영상 | mp4(H.264), 30~60초, 15MB 이하, 소리 없이도 이해되게(자막) | `assets/demo/incident.mp4` + 첫 화면 `assets/demo/incident.jpg` | `story.media = { type: "video", src, poster, caption }` |
| 영상 대신 쓸 화면(GIF·PNG) | 1600px 폭 이하, 2MB 이하 | `assets/demo/incident.png` | `story.media = { type: "image", src, alt, caption }` |
| 각 AI 화면 캡처 | PNG/JPG, 가상 데이터만 | `assets/demo/` | 필요하면 구역을 추가해 연결(말씀 주세요) |
| 고객사 마케팅 사례: 게시물 | 이미지(정사각형 권장) 1000px 이하, 가상 계정에서 AI가 만들고 사람이 승인해 올린 게시물만 | `assets/demo/` | `cases.items[].posts[]`의 `img`·`alt`·`caption`·`date` (캣북스, 누비투어 각각) |
| 고객사 마케팅 사례: 반응 | 도달·좋아요·댓글·저장 등 **실제로 잰 값만**, **잰 날짜와 출처(예: Instagram 인사이트 7일 기준)** | — | `posts[].metrics = [["도달", "123"], …]`, `measuredAt`, `source`. 못 잰 값은 적지 않는다(0으로 채우지 않는다). 날짜·출처가 없으면 숫자가 안 나온다 |

| 연락 수단 | Instagram DM 주소 또는 메일 주소 | — | `links.contactUrl`, `links.contactNote` |

## 규칙 (모든 자료 공통)
1. **가상(시연) 데이터만.** 실제 고객 이름·주문·결제·계좌 정보가 보이면 안 된다.
2. **내부 주소·확인 번호(`rev_...`)·토큰·서버 이름이 화면에 보이면 가리거나 잘라서 넣는다.**
3. 숫자·장면에는 **"시연 환경 기준"**을 붙인다. 측정하지 않은 효과(비용 절감, 인력 대체, "빨라진다")는 쓰지 않는다.
4. 영상은 AI로 만들었으면 "AI가 만든" 표기를 넣는다(합의 문서의 필수 표기).
5. 파일 이름은 영문 소문자와 `-`(예: `incident.mp4`).

## 반영 순서 (받는 쪽)
1. 자료를 `assets/demo/`에 넣고 크기·가상 데이터·가림 여부를 확인한다.
2. `content.mjs`의 해당 칸을 채운다.
3. `node build.mjs`로 만들고, 컴퓨터·휴대폰 폭 모두 눈으로 확인한다.
4. `README.md`의 "확인 필요" 표와 체크리스트를 갱신한다.
5. 준하 님께 반영한 모습을 보여 주고 확인받은 뒤 PR로 올린다.
