# AXcellent 홍보(사이트 광고 · PDF 브로셔 · AXC 마케팅 AI) 공통 합의 초안

상태: **초안**. 작성: 배병환, 2026-11-18. 같이 정할 사람: 김준하. 준하 님이 2026-11-18 10:06에 낸 방향(대상·원칙·핵심 메시지 수정안)을 바탕으로 합쳤다.
이 문서가 맞으면 A(사이트 광고), B(PDF 브로셔), C(AXC 마케팅 AI 운영)가 모두 같은 말을 쓴다. 바꾸려면 둘이 먼저 이 문서를 고친다.

## 1. 대상과 목적
- **대상**: 중소기업 대표(예: 캣북스 같은 동네 책방 + 온라인 규모). 직원이 적어 고객 문의·장애·결제를 대표가 직접 챙기는 사람.
- **목적**: B2B 홍보. 인스타그램 중심, 유료 광고 없이 게시물로 한다. 행동 유도는 브로셔 PDF 받기·상담 DM.
- **원칙**: 비용·위험·효과는 **미끼**(대표의 고민), A2A 자동화는 **증거**. 흐름은 고민 → A2A 자동화로 증명 → 사람 승인으로 안심.
- 12/7 최종발표의 심사위원·멘토는 같은 자료를 보되, 구조 설명은 뒷장에 둔다.

## 2. 핵심 메시지 3줄
1. **AI끼리 알아서 일합니다(A2A 자동화).** 시연 환경 기준 감지부터 기록까지 36초, AI끼리 주고받은 요청 17건.
2. **자동화하되, 돈과 외부 게시는 대표가 승인합니다.** AI가 요청하고 사람이 눌러야 실행됩니다.
3. **한 번 겪은 일은 기억합니다.** 같은 장애가 나면 지난 대응을 찾아 씁니다.

고칠 점 (준하 님 수정안 대비):
- 1번의 "사람 승인 대기 0회"는 2번과 모순처럼 읽힌다. 쓰려면 "시연한 장애 대응에서는 사람 승인이 필요한 일이 없었습니다"처럼 풀어서 쓰고, 그렇지 않다면 뺀다. (준하 님이 의미 확인)
- 36초·요청 17건·28분→1초는 **시연 환경 숫자**다(감지부터 기록까지는 36초가 맞고, 중간발표 자료에는 63초로 적힌 곳이 있어 고쳐야 한다). 출처(어느 시연, 어느 날)를 준하 님이 확정하고 브로셔·게시물에 같은 출처를 쓴다.

## 3. 용어 규칙
- A2A는 **처음 나오는 곳에서 한 줄로 푼다**: "AI 직원끼리 직접 요청을 주고받아, 사람이 중간에서 전달하지 않아도 일이 끝납니다."
- 이후에는 "A2A 자동화"를 이름처럼 반복한다. 용어를 숨기지 않는다(다른 AI 서비스와 구별하는 정체성).
- 처음 쓰는 말은 쉬운 말로 먼저: "AI 직원", "부서 AI", "총괄 AI", "사람 승인". 영어 약어는 한 번 푼 뒤에 쓴다.

## 4. 금지 표현
- 과장: "혁신", "완벽", "100%", "모든 문제를 해결" 같은 단정.
- 측정하지 않은 효과 주장: "인건비 절감", "직원을 대체한다", "에이전트가 빨라진다", "매출이 오른다".
- 시연 숫자를 실제 고객 성과처럼 쓰기. 숫자에는 항상 **"시연 환경 기준"** 또는 **"시연용"**을 붙인다.
- 실제 고객사·개인·계좌·결제 정보 노출(시연 화면은 가상 데이터만).
- "AI가 알아서 결제한다"처럼 돈이 사람 승인 없이 나가는 것으로 읽히는 문장.
- 연출한 상황을 실제 사례처럼 쓰기: 릴스 후크("새벽에 결제가 막혔는데 직원은 퇴근했다")는 **"시연 상황"**이라고 표기한다.

## 5. 필수 표기
- 모든 게시물·브로셔: **"시연 환경 기준"**, **"AI가 만든 게시물"**(게시물만), 가상 데이터면 **"시연용 가상 데이터"**.
- AI 생성 이미지·영상은 마케팅 AI의 AI 라벨 규칙(`sns_label`)을 따른다. 사람이 만든 소재도 AI 생성 여부를 정직하게 적는다.
- 행동 유도 링크는 추적 링크(#1265 `build_campaign_link`)를 쓴다.

## 6. 톤과 색
- **톤**: 차분하고 쉬운 존댓말. 대표의 고민으로 시작하고, 기술 설명은 뒤로. 문장은 짧게, 한 장에 메시지 하나.
- **색(AXcellent 화면 토큰 그대로)**: 본문 글자 `#232345`(ink-900), 강조 `#5B5BD6`(brand-500), 진한 강조·버튼 `#4545B8`(brand-700), 옅은 바탕 `#ECECFB`(brand-50). 흰 바탕 위주.
- **글꼴**: Pretendard(없으면 Noto Sans KR).
- 숫자는 크게 한 개씩 보여 주고 바로 아래에 "시연 환경 기준"을 작게 적는다.

## 7. 게시와 승인 규칙
- 외부 게시(Instagram)는 AI가 요청하고 **사람이 승인한 뒤에만** 올라간다(마케팅 `publish_sns`는 C 등급, 항상 사람 승인).
- 사람이 하는 일은 두 곳뿐: **메시지·소재 방향 입력**, **게시 승인**.
- 승인할 때 확인: 필수 표기(시연·AI 생성) 있음, 금지 표현 없음, 숫자 출처 있음.
- 유료 광고(구글 광고 등)는 이번 범위가 아니다.

## 8. 담당과 맞물림
| 트랙 | 내용 | 담당 |
| --- | --- | --- |
| A. 사이트 광고 | 릴스 15~30초, 카드뉴스 3장(비용·위험·효과) | 병환 |
| B. PDF 브로셔(5~6쪽) | 2·3쪽 A2A 자동화·장애 대응 시연 | 준하 |
| | 4·5쪽 비용·위험·효과 / 안심(대표 승인, 정산 승인 장면 포함), 조립·PDF | 병환 |
| C. AXC 마케팅 AI 운영 | 기획 → 큐 → 프롬프팅 → 영상·이미지 → 게시 승인 → 자동 게시 → 반응 회수 | 준하 (현재 구현 상태를 보고 1차·2차 확정) |

- B → A: 브로셔 2·3쪽 시연 장면을 릴스 소재로 쓴다.
- A → C: 광고 문구와 소재 방향을 C의 기획 입력으로 쓴다.
- C → B: C가 실제로 돌린 게시물과 반응을 "우리도 이렇게 광고한다" 사례로 브로셔에 넣는다.

## 9. 정할 것 (둘이)
1. 핵심 메시지 1번의 "사람 승인 대기 0회" 표현(위 2절).
2. 36초·요청 17건·28분→1초의 출처(어느 시연 이슈 기록, 어느 날)와 표기 문구.
3. 브로셔 4쪽 "비용·위험·효과"에서 쓸 수 있는 근거(측정한 값만, 없으면 질적 서술).
4. 릴스 후크의 "시연 상황" 표기 위치(첫 화면 자막 vs 캡션).
5. C의 1차 범위(기획 → 큐 → 초안 → 승인 화면)와 2차(영상·자동 게시) 경계.
6. 광고 숫자 입력(#1265 B)은 후순위로 두고 추적 링크(C)부터 할지.
