# 재무·세무 규칙 전문가 확인 목록

세무사·회계사에게 확인받을 항목입니다. AI가 공개 자료로 적은 근거라 아직 전문가가 확인하지 않았습니다.
확인이 끝나면 `finance_rules.toml`의 해당 규칙 `review`를 `expert`로 바꿉니다.

## 먼저 답이 필요한 질문

1. 캣북스는 K-IFRS와 일반기업회계기준 중 무엇을 쓰나요? 지금 근거는 K-IFRS로 적었습니다.
2. 판매 수수료를 결제 시점에 잡아도 되나요? 지금은 결제 시각 기준 단순화입니다 (`REV-002`).
3. 약관상 회사 부담 쿠폰이 수수료에서 직접 공제되나요? 에누리 여부가 달라집니다 (`VAT-003`).
4. 판매 수수료와 PG 수수료는 부가세 별도인가요, 포함인가요? (`finance_policy.toml` `[tax]`)
5. 판매자별 명세(제75조) 서식과 사업자등록번호 수집은 어떻게 하나요? (`VAT-005`)
6. 캣북스가 법인세법상 소규모 법인(200억 이하 20%)에 해당하지 않나요? 일반 법인 세율 10·20·22·25%는 [국세청 안내](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?mi=2372&cntntsId=7746)로 확인했고, 해당 여부와 법인지방소득세는 확인하지 못했습니다 (`CIT-001`).

## 규칙별 확인

| 규칙 | 내용 | 적어 둔 근거 | 확인 |
|---|---|---|---|
| `REV-001` 판매 수수료만 매출로 인식 (순액) | 캣북스는 중개자다. 고객 결제액(총거래액)이 아니라 판매 수수료만 매출이다. | K-IFRS 제1115호 B34~B38 (본인과 대리인의 구분) | [ ] |
| `REV-002` 결제 성공 시각에 수수료 인식 | 결제가 성공한 시각이 속한 기간에 수수료를 잡는다. 배송 완료 시점 인식과 다를 수 있는 단순화다. | K-IFRS 제1115호 문단 31 (수행의무 이행 시 인식). 시점은 내부 단순화라 회계사 확인 필요 | [ ] |
| `REV-003` 회사 부담 쿠폰은 매출 차감 | 회사가 부담한 쿠폰은 비용이 아니라 고객에게 지급할 대가로 보아 매출에서 뺀다. | K-IFRS 제1115호 문단 70~72 (고객에게 지급할 대가) | [ ] |
| `EXP-001` PG 수수료는 판매비와관리비 | 결제대행 수수료는 지급수수료로 판매비와관리비에 넣는다. | K-IFRS 제1001호 문단 103 (기능별 분류) | [ ] |
| `EXP-002` 광고비는 판매비와관리비 | 캠페인 광고비는 광고선전비로 판매비와관리비에 넣는다. | K-IFRS 제1001호 문단 103 (기능별 분류) | [ ] |
| `VAT-001` 과세 매출은 판매 수수료 | 판매자의 상품 매출은 판매자가 신고한다. 캣북스의 과세 매출은 중개 수수료다. 면세 도서를 중개해도 수수료는 과세다. | 부가가치세법 제26조 ①8 (도서 면세), 2026-10-30 세무 관점 검토 | [ ] |
| `VAT-002` 매입세액 공제 | 세금계산서를 받은 PG 수수료의 부가세를 매입세액으로 본다. | 부가가치세법 제38조 (공제하는 매입세액) | [ ] |
| `VAT-003` 회사 부담 쿠폰의 과세표준 | 약관상 쿠폰을 수수료에서 직접 공제하면 에누리로 과세표준에서 뺀다. 현금 보전이면 빼지 못할 수 있어 두 값을 모두 보여 준다. | 대법원 2016.6.23. 선고 2014두298 판결 | [ ] |
| `VAT-004` 신고 기한 | 예정 4/25·10/25, 확정 7/25·1/25 (법인 기준). | 부가가치세법 제48조, 제49조 | [ ] |
| `VAT-005` 판매자별 판매·중개 명세 | 분기 말일의 다음 달 15일까지. 서식은 국세청 고시 확인 전 초안이고 사업자등록번호는 자료가 없어 비운다. | 부가가치세법 제75조 | [ ] |
| `CIT-001` 법인세 참고 추정 | 장부의 영업 결과에 법인세율을 곱한 참고치다. 세무조정과 급여·임차료가 빠져 있어 신고에 쓰지 않는다. | 법인세법 제55조 ①, 국세청 법인세 세율 안내 (2026-11-04 확인). 법인지방소득세 지방세법 제103조의20은 원문 미확인. 세무조정은 세무사 업무 | [ ] |
| `CMP-001` 캠페인 매출은 수수료 기준 | 캠페인 매출 = 증분 판매액 × 판매 수수료율. 판매액 전체를 매출로 보면 적자가 흑자로 보인다. | REV-001과 같은 기준 (K-IFRS 제1115호 B34~B38) | [ ] |

내부 기준 규칙(브레이크, 교훈, 인사이트)은 전문가 확인 대상이 아니라 재무 담당이 정합니다.
