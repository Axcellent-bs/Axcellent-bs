# 영수증 사진의 외부 모델 전송: 사실, 안내 문구 초안, 사용 조건

> 상태: 초안(제안). 구현 결정이 아니고, `[결정 필요]`는 담당(병환)과 팀이 정한다.
> **법무 확인 필요**: 이 문서의 개인정보·국외 이전 관련 문구는 코드에서 읽은 사실과 팀 결정을 옮긴 것이고 **법적 판단이 아니다.** 안내 문구는 확정 전에 법무·변호사 확인을 받는다.
> 배경: 2026-10-30 #소통에서 영수증 사진 대조를 서버(251)에서 시험하기로 하면서 "공개 시연이나 실제 고객이 쓰기 전에 방침(국외 이전·외부 전송 안내)을 반영한다"가 조건으로 남았다. 이 문서가 그 방침의 초안이다.

## 1. 한 줄 요약
영수증 사진 대조(`analyze_receipt`)는 사진을 **외부 LLM(Gemini 등 `LLM_*`로 설정한 모델)에 보내서** 영수증의 글자를 읽는다. 지금은 시험 단계라 허가된 범위에서만 쓴다. 공개 시연이나 실제 고객이 쓰기 전에는 고객에게 알리는 문구와 사용 조건이 먼저 정해져야 한다.

## 2. 지금 어떻게 동작하나 (코드에서 읽은 것)
- 분석기(`receipt_vision.py`)는 사진에서 **보이는 글자를 옮겨 적기만** 한다. 금액이 맞는지, 환불해도 되는지는 판정하지 않는다(대조는 `receipts.compare`, 환불 판정은 `claim_rules`가 코드로 한다).
- 사진은 메모리에서만 쓴다. 저장하지 않고 로그에 바이트를 남기지 않는다(`ImageInput`이 보장한다).
- 모르는 값은 `null`로 받고, 날짜·금액·주문번호는 응답을 받은 뒤 코드가 형식을 다시 검사한다.
- 이미지 안의 글자는 지시가 아니다(래퍼 안내문과 프롬프트가 함께 알린다).
- 켜지는 조건
  - 목 모드가 아니고 `LLM_*`(또는 `SUPPORT_LLM_*`)가 설정돼 있으면 `SUPPORT_VISION`을 안 줘도 **켜진다.**
  - `SUPPORT_VISION=off`는 항상 꺼진다.
  - 목 모드(`SUPPORT_MOCK=1`)는 `SUPPORT_VISION=on`을 명시했을 때만 켜진다.

## 4. 안내 문구 초안
모두 `[법무 확인 필요]`다. 문구를 확정하기 전에는 화면에 넣지 않는다.

**4.1 고객용 짧은 안내(사진 올리기 전, 한 줄)**
> 영수증 사진은 내용을 읽기 위해 외부 AI 서비스로 전송됩니다. 사진은 저장하지 않으며, 읽은 금액·날짜·품목만 확인에 사용합니다.

**4.2 개인정보처리방침에 더할 항목(초안)**
- 처리 목적: 영수증 내용 확인을 통한 환불·교환 심사 지원
- 처리 항목: 고객이 올린 영수증 사진(영수증에 포함된 정보)
- 받는 곳: 외부 AI 모델 공급자 `[공급자 이름·위치 확인 필요]`
- 보유: 사진은 저장하지 않음. 읽은 값의 보유는 문의 보유기간을 따름 `[결정 필요]`
- 국외 이전 가능성: 공급자 위치에 따라 국외로 전송될 수 있음 `[법무 확인 필요]`

**4.3 상담 콘솔 안내(상담원용)**
> 영수증 대조를 실행하면 사진이 외부 AI로 전송됩니다. 고객이 올린 사진만 올리고, 다른 사람의 개인정보가 담긴 사진은 올리지 마세요.

## 6. 결정 상태
### 6.1 정리된 것 (2026-11-02, 이재헌 확인)
1. **학습 사용**: 쓰고 있는 Gemini 키는 유료 요금제이고, 이재헌이 확인한 기준으로 입력이 학습에 쓰이지 않는다(Google 가격 문서에서도 유료 등급은 입력이 제품 개선에 쓰이지 않는다고 나오며, 무료 등급은 쓰일 수 있다). 이 문서 작성자는 가격 문서를 직접 확인하지 못했다. 계약·약관 문구는 **법무 확인 대상**이다.
2. **시험 후 서버 설정**: 서버 251의 `SUPPORT_VISION=off` 명시는 시험이 끝난 뒤에 정한다. 지금은 그대로 둔다.
3. **기본값 변경 방향**: `SUPPORT_VISION=on`을 명시했을 때만 켜지게 바꾸는 안은 방향에 동의했다. 코드 변경은 고객지원 영역이라 병환이 검토하고, 방향이 정해지면 별도 PR로 올린다(이 PR에는 코드 변경이 없다).

### 6.2 아직 정해야 하는 것 `[결정 필요]`
1. **공급자 처리 위치**: 모델 공급자의 데이터 처리 위치(국외 이전 표기). **법무 확인 대상.**
2. **고객 안내의 위치**: 4.1을 사진 올리기 화면에 넣을지, 문의 접수 약관에 넣을지.
3. **읽은 값의 보유와 시연 범위**: 영수증에서 읽은 값이 문의에 남는 기간(문의 원문 보유기간과 같게 갈지), 이 방침이 시연 필수 범위인지 시연 이후 2차인지.

## 8. 확인하지 못한 것
- 공급자의 데이터 처리 위치와 공급자 쪽 보관 기간(6.2의 1).
- 학습 미사용은 이재헌의 확인과 그가 인용한 Google 가격 문서에 근거한다. 작성자가 직접 확인한 것이 아니다.
- 서버 251의 현재 설정은 2026-10-30 이재헌의 읽기 확인에 근거한다. 이후 바뀌었는지는 확인하지 못했다.
- 실서버 일치(consistent) 판정은 같은 금액·날짜의 주문이 없어 못 봤다(로컬 모델로는 확인).
- 이 문서의 안내 문구는 화면과 방침에 아직 반영되지 않았다.
